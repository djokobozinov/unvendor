# Generative AI log

One file per AI-assisted session, named `YYYY-MM-DD-<topic>.md`. Each entry records:

- **Date** of the session.
- **Model**, with its exact name and version.
- **Prompts**: the requests made, quoted when short, otherwise summarised.
- **Produced**: what the assistant generated, and which files and commits it ended up in.

Commits with AI-generated content carry an `Assisted-by:` trailer and can link to the matching entry here. See [Use of generative AI](../../README.md#use-of-generative-ai) in the README.
